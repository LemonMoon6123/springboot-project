# LiveHouse 电子票二维码功能

## 功能说明

已为LiveHouse票务系统添加轻量级的二维码功能，用户可以在票夹中查看电子票的二维码。

## 实现方式

- **纯前端实现**：使用 `qrcode.js` 库生成二维码，无需后端改动
- **轻量级**：仅添加一个依赖（qrcode: ^1.5.3）
- **兼容现有系统**：二维码内容就是票号，扫码后直接调用现有的验票API

## 使用方法

### 用户端
1. 登录系统并购买门票
2. 在"票夹"页面查看已购买的电子票
3. 点击票卡上的"显示二维码"按钮
4. 向工作人员出示二维码完成验票

### 管理员端（验票）
1. 使用扫码设备扫描用户的二维码
2. 扫码设备会获取到票号（如：ET123456789...）
3. 将票号输入到"现场核销"功能中，或调用验票API
4. 系统返回验票结果

## 技术特点

### 优势
- **简单**：无需复杂的后端改动
- **轻量**：只添加了一个小型JS库
- **兼容**：完全兼容现有的验票接口
- **安全**：基于现有的票号验证机制

### 二维码内容
```
票号内容：ET123456789012345678
二维码：直接包含上述票号字符串
```

### 扫码验票流程
```
用户展示二维码 → 扫码设备识别 → 获取票号 → 调用 /ticket/verify/{票号} → 返回验票结果
```

## 安装步骤

1. 在前端项目目录运行：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

3. 无需其他配置，功能即可正常使用
