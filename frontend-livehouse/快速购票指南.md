# 快速购票指南

## 🚀 5分钟内获得电子票（含二维码）

### 1. 登录
- 访问：http://localhost:5173
- 点击右上角"登录"
- 手机号：`13800138000`
- 验证码：任意输入（如 `123456`）

### 2. 选择演出
- 在首页点击任意一个演出卡片
- 进入演出详情页

### 3. 购票
- 选择票种（第一个会自动选中）
- 确认数量（默认1张）
- 点击"立即抢票"
- 看到"抢票成功，请在订单中完成支付"

### 4. 支付
- 点击顶部"订单"
- 找到状态为"待支付"的订单
- 点击"去支付"
- 看到"支付成功"
- 会弹出电子票生成窗口

### 5. 查看二维码
- 点击顶部"票夹"
- 找到刚购买的电子票卡片
- **在票号下方应该有"显示二维码"按钮**
- 点击按钮查看二维码
