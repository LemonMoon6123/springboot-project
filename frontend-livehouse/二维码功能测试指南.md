# 二维码功能测试指南

## 🎯 测试步骤

### 第一步：确认系统状态

1. **启动后端服务**
   ```bash
   # 在项目根目录
   mvn spring-boot:run
   # 或运行主类 LivehouseTicketApplication
   ```

2. **启动前端服务**
   ```bash
   cd frontend-livehouse
   npm install  # 确保依赖已安装
   npm run dev
   ```

3. **访问前端**
   - 打开浏览器访问：`http://localhost:5173`

### 第二步：登录账户

1. 点击右上角"登录"按钮
2. 输入手机号：`13800138000`
3. 输入任意验证码（如：`123456`）
4. 点击"登录"

### 第三步：购买电子票

1. **选择演出**
   - 在首页点击任意演出卡片
   
2. **选择票种**
   - 选择一个票种（会自动选中第一个）
   - 确认数量（默认1张）
   
3. **抢票**
   - 点击"立即抢票"按钮
   - 应该显示"抢票成功，请在订单中完成支付"

4. **查看订单**
   - 点击顶部"订单"按钮
   - 找到刚才的订单，状态应该是"待支付"
   
5. **支付订单**
   - 点击订单的"去支付"按钮
   - 应该显示"支付成功"
   - 会弹出电子票生成的模态框

### 第四步：查看二维码

1. **进入票夹**
   - 点击顶部"票夹"按钮
   - 应该看到刚才购买的电子票

2. **检查票卡内容**
   每张票卡应该包含：
   - 演出海报图片
   - 演出名称和票种
   - 场馆信息
   - 票号（如：ET123456789...）
   - **"显示二维码"按钮**

3. **显示二维码**
   - 点击"显示二维码"按钮
   - 应该弹出二维码模态框
   - 模态框包含：
     - 演出信息
     - 清晰的二维码图片
     - 票号信息

### 第五步：测试验票

1. **使用手机扫描**
   - 用手机的相机或扫码应用扫描二维码
   - 应该识别出票号内容（如：ET123456789...）

2. **管理员验票**
   - 点击顶部"管理员端"
   - 在"现场核销"中输入扫描到的票号
   - 点击"确认核销"
   - 应该显示"核销成功"

3. **再次查看票夹**
   - 回到票夹页面
   - 票卡状态应该变为"已使用"
   - "显示二维码"按钮应该变为"已使用"且禁用

## 🐛 常见问题排查

### 问题1：看不到"显示二维码"按钮

**可能原因：**
- 没有购买电子票
- 票夹页面显示"支付成功后，电子票会出现在这里"

**解决方法：**
1. 按照上述步骤完成购票流程
2. 确保订单已支付
3. 刷新票夹页面

### 问题2：点击按钮没有反应

**可能原因：**
- JavaScript错误
- qrcode库加载失败

**排查方法：**
1. 按F12打开浏览器开发者工具
2. 查看Console标签是否有错误信息
3. 检查Network标签是否有加载失败的资源

**解决方法：**
```bash
# 重新安装依赖
cd frontend-livehouse
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### 问题3：二维码显示空白

**可能原因：**
- Canvas渲染失败
- 票号内容为空

**解决方法：**
1. 检查浏览器控制台错误
2. 确认票号不为空
3. 尝试不同浏览器

### 问题4：扫码无法识别

**可能原因：**
- 二维码质量问题
- 扫码应用问题

**解决方法：**
1. 调整屏幕亮度
2. 尝试不同的扫码应用
3. 手动输入票号进行验票

## 📱 移动端测试

1. **手机浏览器访问**
   - 在手机浏览器中访问：`http://你的电脑IP:5173`
   - 完成购票流程
   - 测试二维码显示

2. **扫码测试**
   - 用另一部手机扫描二维码
   - 或使用电脑摄像头扫描

## ✅ 成功标志

如果以下都能正常工作，说明二维码功能正常：

- [x] 能够看到"显示二维码"按钮
- [x] 点击按钮能弹出二维码模态框
- [x] 二维码清晰可见
- [x] 手机能够扫描识别出票号
- [x] 使用票号能够成功验票
- [x] 已使用的票显示正确状态
