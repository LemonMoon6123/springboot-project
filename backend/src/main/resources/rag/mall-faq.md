# 智购商城常见问题

## 下单与支付
- 下单前请先登录用户账号，并将心仪商品加入购物车。
- 创建订单需要选择收货地址，并勾选购物车中的商品项。
- 订单创建后为「待支付」状态，可在「我的订单」中完成支付。
- 本站为演示商城，支付为模拟支付，不会产生真实扣款。

## 购物车
- 可在商品详情页或 AI 导购对话中将商品加入购物车。
- 购物车支持修改数量、删除商品。
- AI Agent 可代查购物车、加购；真正下单前会再次确认。

## 物流与发货
- 商家发货后订单变为「已发货」，可在订单详情查看物流信息。
- 确认收货后订单变为「已完成」。

## 售后
- 已支付订单可申请售后（退款/退货退款/换货）。
- 商家处理售后申请后，状态会更新为已同意或已拒绝。

## AI 导购
- 支持文字描述需求（预算、品类、场景）推荐商品。
- 支持上传图片识图找相似商品。
- Agent 可结合商城政策知识库（RAG）回答售后与购物流程问题。
