# 数据大屏功能说明

## 功能概述

数据大屏是为管理员端专门设计的数据统计和分析功能，提供实时的业务数据展示和分析报表。

## 主要功能

### 1. 总体概览
- 总演出数量
- 总订单数量
- 已支付订单数量
- 总营收
- 平均客单价
- 支付成功率

### 2. 营收分析
- 今日营收
- 近7天营收
- 近30天营收
- 近1年营收
- 近7天营收趋势图表

### 3. 演出统计
- 各演出售票情况
- 演出营收排名
- 热门演出TOP5
- 核销统计

### 4. 订单统计
- 今日订单数量
- 订单状态分布（待支付、已完成、已取消、已退票）
- 支付状态分布
- 24小时订单趋势

### 5. 限流统计
- 当前活跃限流数
- 限流策略信息
- 近期限流记录
- IP访问频率排行

### 6. 访问统计
- 今日访问量
- 独立访客数
- 页面浏览量
- 实时在线用户数
- 访问来源分布
- 热门页面排行
- 近7天访问趋势

### 7. 实时数据
- 系统运行状态
- 最近1小时订单数
- 最近1小时营收
- 数据更新时间

## 技术实现

### 后端架构

#### 1. 服务层
- `IDataScreenService`: 数据大屏服务接口
- `DataScreenServiceImpl`: 服务实现类，负责数据查询和统计

#### 2. 控制器
- `AdminController`: 管理员控制器，新增数据大屏相关接口
  - `/admin/data-screen/overview` - 总体概览
  - `/admin/data-screen/revenue` - 营收分析
  - `/admin/data-screen/shows` - 演出统计
  - `/admin/data-screen/orders` - 订单统计
  - `/admin/data-screen/rate-limit` - 限流统计
  - `/admin/data-screen/visits` - 访问统计
  - `/admin/data-screen/realtime` - 实时数据
  - `/admin/data-screen/all` - 获取所有数据（一次性）

#### 3. 数据结构
- 使用 `Map<String, Object>` 结构返回统计数据
- 键值对形式：`"统计项名称": 统计值`
- 支持嵌套结构和列表数据

### 前端实现

#### 1. 界面设计
- 响应式网格布局
- 美观的卡片式设计
- 渐变色主题
- 移动端适配

#### 2. 功能特性
- 数据大屏开关控制
- 手动刷新数据
- 自动刷新功能（30秒间隔）
- 加载状态提示
- 错误处理

#### 3. 数据可视化
- 营收趋势柱状图
- 演出排行榜
- 状态分布统计
- 实时指标展示

## 使用方法

1. **访问数据大屏**
   - 进入管理员端
   - 点击"数据大屏"卡片中的"打开数据大屏"按钮

2. **查看数据**
   - 数据大屏会自动加载所有统计数据
   - 各个模块独立展示不同维度的数据

3. **刷新数据**
   - 手动刷新：点击"刷新数据"按钮
   - 自动刷新：点击"开启自动刷新"，每30秒自动更新

4. **关闭大屏**
   - 点击"关闭数据大屏"按钮
   - 自动刷新会同时停止

## 数据来源

### 数据库查询
- 票务订单表（`tb_ticket_order`）
- 演出信息表（`tb_show`）
- 电子票表（`tb_electronic_ticket`）
- 用户表等

### Redis统计
- 核销BitMap统计
- 限流记录
- 库存信息

### 示例数据
- 访问统计（可集成第三方统计服务）
- 限流记录（可从监控系统获取）

## 扩展建议

### 1. 数据增强
- 集成Google Analytics或百度统计
- 添加更多业务维度统计
- 引入机器学习预测分析

### 2. 可视化升级
- 集成专业图表库（如ECharts、Chart.js）
- 添加更多图表类型（饼图、折线图等）
- 支持数据导出功能

### 3. 实时性优化
- 使用WebSocket推送实时数据

- 添加数据预警功能

### 4. 权限控制
- 添加数据查看权限控制
- 支持不同级别的数据展示
- 操作日志记录

## 性能考虑

1. **数据查询优化**
   - 合理使用数据库索引
   - 批量查询减少数据库访问
   - 复杂统计可考虑定时任务预计算

2. **缓存策略**
   - Redis缓存热点统计数据
   - 设置合理的缓存过期时间
   - 支持缓存更新机制

3. **前端优化**
   - 异步加载各模块数据
   - 避免频繁的全量刷新
   - 合理的loading状态处理

## 注意事项

1. **数据安全**
   - 管理员端功能，注意权限控制
   - 敏感数据脱敏处理
   - 接口访问频率限制

2. **系统稳定**
   - 大数据量查询注意性能影响
   - 异常处理和降级方案
   - 监控和告警机制

3. **扩展性**
   - 模块化设计便于功能扩展
   - 统一的数据格式规范
   - 预留接口和扩展点
