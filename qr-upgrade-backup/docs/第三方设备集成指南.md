# 第三方扫码设备集成指南

## 概述

LiveHouse票务系统提供了完整的第三方设备集成解决方案，支持各种类型的扫码设备：
- PDA手持终端
- 固定式扫码器
- 闸机设备
- 移动验票设备
- 自助验票终端

## 集成架构

```
┌─────────────────┐    HTTP/HTTPS     ┌─────────────────┐
│   第三方设备    │ ─────────────→   │  LiveHouse API  │
│  (扫码设备)     │                   │                 │
├─────────────────┤                   ├─────────────────┤
│ • 扫码模块      │                   │ • 验票服务      │
│ • HTTP客户端    │ ←─────────────   │ • 安全验证      │
│ • 结果处理      │    JSON响应       │ • 日志记录      │
└─────────────────┘                   └─────────────────┘
```

## API接口规范

### 1. 认证方式

所有第三方设备请求都需要API Key认证：

```http
POST /mobile/ticket/third-party-verify
Content-Type: application/json
X-API-Key: your-api-key-here

{
  "qrCodeData": "扫描到的二维码内容",
  "deviceId": "设备唯一标识",
  "deviceModel": "设备型号",
  "vendor": "设备厂商"
}
```

### 2. 标准响应格式

**成功响应：**
```json
{
  "success": true,
  "data": {
    "success": true,
    "message": "VERIFY_SUCCESS",
    "timestamp": 1634567890123,
    "deviceId": "DEVICE001"
  }
}
```

**失败响应：**
```json
{
  "success": false,
  "errorMsg": "电子票已核销",
  "errorCode": "TICKET_ALREADY_VERIFIED"
}
```

package com.example.ticketscanner;

import android.os.AsyncTask;
import android.util.Log;
import com.google.gson.Gson;
import com.google.gson.annotations.SerializedName;
import okhttp3.*;
import java.io.IOException;
import java.util.concurrent.TimeUnit;

public class TicketScannerManager {
    private static final String TAG = "TicketScanner";
    private static final String BASE_URL = "https://your-livehouse-api.com";
    private static final String API_KEY = "your-api-key-here";
    
    private OkHttpClient httpClient;
    private Gson gson;
    private ScanResultCallback callback;
    
    public interface ScanResultCallback {
        void onScanSuccess(String message);
        void onScanFailure(String error);
        void onNetworkError(String error);
    }
    
    public TicketScannerManager() {
        // 初始化HTTP客户端
        this.httpClient = new OkHttpClient.Builder()
                .connectTimeout(10, TimeUnit.SECONDS)
                .writeTimeout(10, TimeUnit.SECONDS)
                .readTimeout(30, TimeUnit.SECONDS)
                .build();
        
        this.gson = new Gson();
    }
    
    public void setScanResultCallback(ScanResultCallback callback) {
        this.callback = callback;
    }
    
    /**
     * 验证扫描到的票据
     */
    public void verifyTicket(String qrCodeData) {
        DeviceInfo deviceInfo = getDeviceInfo();
        
        VerifyRequest request = new VerifyRequest();
        request.qrCodeData = qrCodeData;
        request.deviceId = deviceInfo.deviceId;
        request.deviceModel = deviceInfo.model;
        request.vendor = deviceInfo.vendor;
        request.firmwareVersion = deviceInfo.firmwareVersion;
        
        // 异步执行网络请求
        new VerifyTicketTask().execute(request);
    }
    
    private DeviceInfo getDeviceInfo() {
        DeviceInfo info = new DeviceInfo();
        info.deviceId = android.os.Build.SERIAL;
        info.model = android.os.Build.MODEL;
        info.vendor = android.os.Build.MANUFACTURER;
        info.firmwareVersion = android.os.Build.VERSION.RELEASE;
        return info;
    }
    
    private class VerifyTicketTask extends AsyncTask<VerifyRequest, Void, VerifyResponse> {
        
        @Override
        protected VerifyResponse doInBackground(VerifyRequest... requests) {
            try {
                VerifyRequest request = requests[0];
                String jsonRequest = gson.toJson(request);
                
                RequestBody body = RequestBody.create(
                    jsonRequest, MediaType.get("application/json; charset=utf-8")
                );
                
                Request httpRequest = new Request.Builder()
                    .url(BASE_URL + "/mobile/ticket/third-party-verify")
                    .addHeader("X-API-Key", API_KEY)
                    .post(body)
                    .build();
                
                try (Response response = httpClient.newCall(httpRequest).execute()) {
                    String responseBody = response.body().string();
                    
                    if (response.isSuccessful()) {
                        ApiResponse apiResponse = gson.fromJson(responseBody, ApiResponse.class);
                        return new VerifyResponse(true, apiResponse.data.message, null);
                    } else {
                        ErrorResponse errorResponse = gson.fromJson(responseBody, ErrorResponse.class);
                        return new VerifyResponse(false, null, errorResponse.errorMsg);
                    }
                }
                
            } catch (IOException e) {
                Log.e(TAG, "Network error during ticket verification", e);
                return new VerifyResponse(false, null, "网络连接失败: " + e.getMessage());
            } catch (Exception e) {
                Log.e(TAG, "Unexpected error during ticket verification", e);
                return new VerifyResponse(false, null, "系统错误: " + e.getMessage());
            }
        }
        
        @Override
        protected void onPostExecute(VerifyResponse result) {
            if (callback != null) {
                if (result.success) {
                    callback.onScanSuccess(result.message);
                } else {
                    callback.onScanFailure(result.error);
                }
            }
        }
    }
    
    // 数据类定义
    private static class VerifyRequest {
        @SerializedName("qrCodeData")
        String qrCodeData;
        
        @SerializedName("deviceId")
        String deviceId;
        
        @SerializedName("deviceModel")
        String deviceModel;
        
        @SerializedName("vendor")
        String vendor;
        
        @SerializedName("firmwareVersion")
        String firmwareVersion;
    }
    
    private static class ApiResponse {
        @SerializedName("success")
        boolean success;
        
        @SerializedName("data")
        VerifyData data;
    }
    
    private static class VerifyData {
        @SerializedName("success")
        boolean success;
        
        @SerializedName("message")
        String message;
        
        @SerializedName("timestamp")
        long timestamp;
        
        @SerializedName("deviceId")
        String deviceId;
    }
    
    private static class ErrorResponse {
        @SerializedName("success")
        boolean success;
        
        @SerializedName("errorMsg")
        String errorMsg;
        
        @SerializedName("errorCode")
        String errorCode;
    }
    
    private static class DeviceInfo {
        String deviceId;
        String model;
        String vendor;
        String firmwareVersion;
    }
    
    private static class VerifyResponse {
        final boolean success;
        final String message;
        final String error;
        
        VerifyResponse(boolean success, String message, String error) {
            this.success = success;
            this.message = message;
            this.error = error;
        }
    }
}

public class MainActivity extends AppCompatActivity {

class TicketVerifier:
    """票务验证器"""
    
    def __init__(self, config: DeviceConfig):
        self.config = config
        self.session = requests.Session()
        self.session.headers.update({
            'Content-Type': 'application/json',
            'X-API-Key': self.config.api_key,
            'User-Agent': f'{self.config.vendor}-{self.config.device_model}/{self.config.firmware_version}'
        })
        
    def verify_ticket(self, qr_code_data: str) -> VerifyResult:
        """
        验证票据
        
        Args:
            qr_code_data: 扫描到的二维码数据
            
        Returns:
            VerifyResult: 验证结果
        """
        try:
            payload = {
                'qrCodeData': qr_code_data,
                'deviceId': self.config.device_id,
                'deviceModel': self.config.device_model,
                'vendor': self.config.vendor,
                'firmwareVersion': self.config.firmware_version
            }
            
            logger.info(f"发送验票请求 - 设备: {self.config.device_id}")
            
            response = self.session.post(
                f'{self.config.api_url}/mobile/ticket/third-party-verify',
                json=payload,
                timeout=self.config.timeout
            )
            
            if response.status_code == 200:
                data = response.json()
                if data.get('success'):
                    verify_data = data.get('data', {})
                    return VerifyResult(
                        success=True,
                        message=verify_data.get('message', '验票成功'),
                        timestamp=verify_data.get('timestamp')
                    )
                else:
                    return VerifyResult(
                        success=False,
                        message=data.get('errorMsg', '验票失败'),
                        error_code=data.get('errorCode')
                    )
            else:
                return VerifyResult(
                    success=False,
                    message=f'HTTP错误: {response.status_code}',
                    error_code='HTTP_ERROR'
                )
                
        except requests.exceptions.ConnectTimeout:
            logger.error("连接超时")
            return VerifyResult(success=False, message='连接超时', error_code='TIMEOUT')
            
        except requests.exceptions.ConnectionError:
            logger.error("连接错误")
            return VerifyResult(success=False, message='网络连接失败', error_code='CONNECTION_ERROR')
            
        except requests.exceptions.RequestException as e:
            logger.error(f"请求异常: {e}")
            return VerifyResult(success=False, message=f'请求异常: {str(e)}', error_code='REQUEST_ERROR')
            
        except json.JSONDecodeError:
            logger.error("响应数据格式错误")
            return VerifyResult(success=False, message='服务器响应格式错误', error_code='JSON_ERROR')
            
        except Exception as e:
            logger.error(f"未知错误: {e}")
            return VerifyResult(success=False, message=f'系统错误: {str(e)}', error_code='UNKNOWN_ERROR')

using System;
using System.Net.Http;
using System.Text;

namespace LiveHouse.TicketScanner
{
    public class TicketVerifierClient
    {
        private readonly HttpClient _httpClient;
        private readonly DeviceConfig _config;

        public TicketVerifierClient(DeviceConfig config)
        {
            _config = config;
            _httpClient = new HttpClient()
            {
                Timeout = TimeSpan.FromSeconds(config.TimeoutSeconds)
            };
            
            _httpClient.DefaultRequestHeaders.Add("X-API-Key", config.ApiKey);
            _httpClient.DefaultRequestHeaders.Add("User-Agent", 
                $"{config.Vendor}-{config.DeviceModel}/{config.FirmwareVersion}");
        }

        public async Task<VerifyResult> VerifyTicketAsync(string qrCodeData)
        {
            try
            {
                var request = new VerifyRequest
                {
                    QrCodeData = qrCodeData,
                    DeviceId = _config.DeviceId,
                    DeviceModel = _config.DeviceModel,
                    Vendor = _config.Vendor,
                    FirmwareVersion = _config.FirmwareVersion
                };

                var jsonContent = JsonConvert.SerializeObject(request);
                var content = new StringContent(jsonContent, Encoding.UTF8, "application/json");

                var response = await _httpClient.PostAsync(
                    $"{_config.ApiUrl}/mobile/ticket/third-party-verify", 
                    content);

                var responseContent = await response.Content.ReadAsStringAsync();

                if (response.IsSuccessStatusCode)
                {
                    var apiResponse = JsonConvert.DeserializeObject<ApiResponse>(responseContent);
                    
                    return new VerifyResult
                    {
                        Success = true,
                        Message = apiResponse.Data.Message,
                        Timestamp = apiResponse.Data.Timestamp,
                        DeviceId = apiResponse.Data.DeviceId
                    };
                }
                else
                {
                    var errorResponse = JsonConvert.DeserializeObject<ErrorResponse>(responseContent);
                    
                    return new VerifyResult
                    {
                        Success = false,
                        Message = errorResponse.ErrorMsg,
                        ErrorCode = errorResponse.ErrorCode
                    };
                }
            }
            catch (HttpRequestException ex)
            {
                return new VerifyResult
                {
                    Success = false,
                    Message = $"网络错误: {ex.Message}",
                    ErrorCode = "NETWORK_ERROR"
                };
            }
            catch (TaskCanceledException ex)
            {
                return new VerifyResult
                {
                    Success = false,
                    Message = "请求超时",
                    ErrorCode = "TIMEOUT"
                };
            }
            catch (Exception ex)
            {
                return new VerifyResult
                {
                    Success = false,
                    Message = $"系统错误: {ex.Message}",
                    ErrorCode = "SYSTEM_ERROR"
                };
            }
        }

        public void Dispose()
        {
            _httpClient?.Dispose();
        }
    }

        private readonly TicketVerifierClient _verifier;
        private readonly DeviceConfig _config;

        public TicketScannerApp()
        {
            _config = LoadConfiguration();
            _verifier = new TicketVerifierClient(_config);
        }

        private DeviceConfig LoadConfiguration()
        {
            var configuration = new ConfigurationBuilder()
                .SetBasePath(AppDomain.CurrentDomain.BaseDirectory)
                .AddJsonFile("appsettings.json", optional: false, reloadOnChange: true)
                .Build();

            return new DeviceConfig
            {
                ApiUrl = configuration["LiveHouse:ApiUrl"],
                ApiKey = configuration["LiveHouse:ApiKey"],
                DeviceId = configuration["Device:Id"],
                DeviceModel = configuration["Device:Model"],
                Vendor = configuration["Device:Vendor"],
                FirmwareVersion = configuration["Device:FirmwareVersion"],
                TimeoutSeconds = int.Parse(configuration["Network:TimeoutSeconds"] ?? "30")
            };
        }

        public async Task RunAsync()
        {
            Console.WriteLine($"LiveHouse票务扫码器启动");
            Console.WriteLine($"设备: {_config.DeviceModel} ({_config.DeviceId})");
            Console.WriteLine($"厂商: {_config.Vendor}");
            Console.WriteLine($"版本: {_config.FirmwareVersion}");
            Console.WriteLine("请扫描二维码，输入'exit'退出\n");

            while (true)
            {
                Console.Write("扫码结果: ");
                var input = Console.ReadLine();

                if (string.IsNullOrWhiteSpace(input))
                    continue;

                if (input.ToLower() == "exit")
                    break;

                await ProcessScanResult(input);
            }

            _verifier.Dispose();
            Console.WriteLine("应用程序已退出");
        }

        private async Task ProcessScanResult(string qrCodeData)
        {
            Console.WriteLine("正在验证票据...");

            var result = await _verifier.VerifyTicketAsync(qrCodeData);

            if (result.Success)
            {
                Console.ForegroundColor = ConsoleColor.Green;
                Console.WriteLine($"✓ 验票成功: {result.Message}");
                Console.ResetColor();
                
                // 这里可以控制硬件设备，如LED、蜂鸣器等
                PlaySuccessSound();
            }
            else
            {
                Console.ForegroundColor = ConsoleColor.Red;
                Console.WriteLine($"✗ 验票失败: {result.Message}");
                if (!string.IsNullOrEmpty(result.ErrorCode))
                {
                    Console.WriteLine($"错误代码: {result.ErrorCode}");
                }
                Console.ResetColor();
                
                PlayErrorSound();
            }

            Console.WriteLine();
        }

        private void PlaySuccessSound()
        {
            // Windows系统声音
            Console.Beep(1000, 200);
        }

        private void PlayErrorSound()
        {
            // Windows系统声音
            Console.Beep(500, 500);
        }
    }

    // 程序入口
    class Program
    {
        static async Task Main(string[] args)
        {
            try
            {
                var app = new TicketScannerApp();
                await app.RunAsync();
            }
            catch (Exception ex)
            {
                Console.ForegroundColor = ConsoleColor.Red;
                Console.WriteLine($"程序异常: {ex.Message}");
                Console.ResetColor();
                
                Console.WriteLine("按任意键退出...");
                Console.ReadKey();
            }
        }
    }
}

## 故障排除

### 常见错误及解决方案

1. **API Key无效**
   ```json
   {"success": false, "errorMsg": "无效的API密钥"}
   ```
   - 检查API密钥是否正确
   - 确认密钥未过期
   - 联系管理员重新生成

2. **网络连接失败**
   ```
   ConnectTimeout/ConnectionError
   ```
   - 检查网络连接
   - 确认API服务器地址正确
   - 检查防火墙设置

3. **票据已核销**
   ```json
   {"success": false, "errorMsg": "电子票已核销"}
   ```
   - 正常业务逻辑，票据只能使用一次
   - 检查是否重复扫描

4. **二维码格式错误**
   ```json
   {"success": false, "errorMsg": "二维码格式错误或已损坏"}
   ```
   - 确认二维码清晰度
   - 检查扫码设备功能
   - 验证二维码是否为有效票据
